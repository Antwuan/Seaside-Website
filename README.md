# Seaside Web Studio

Marketing site for Seaside Web Studio, a studio that builds branded websites for small businesses — shops, restaurants, and appointment desks.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The contact form opens the visitor’s email app addressed to `hello@seasidewebstudio.com`. That mailbox has to exist on the domain after it is purchased.
